# Локальный показ сайта РУСВЕКТОР

1. Дважды нажмите `Показать сайт.command`.
2. В браузере откроется `http://localhost:3000`.
3. Чтобы остановить сайт, закройте окно Терминала или нажмите `Ctrl + C`.

Для запуска нужен Node.js и pnpm. Исходники и изображения лежат в этой папке; публикация через ChatGPT Sites не используется.
